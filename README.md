# The Twenty-Seven

An interactive atlas of the 27 canonical New Testament documents. Choose any two dimensions and compare the whole canon as a scatter plot.

Built as a companion to Dale B. Martin's Yale RLST 152 course.

## Dimensions

- probable date, with uncertainty ranges
- Greek length
- Torah orientation
- Jewish/Gentile orientation
- eschatological imminence
- Christological explicitness
- ecclesial structure
- posture toward imperial order
- wealth critique
- household-order emphasis
- universal scope
- narrative/discourse
- autobiographical voice
- theological elaboration
- apocalyptic intensity

Interpretive scores are comparative editorial models, not empirical measurements. The interface is designed to make the assumptions visible and revisable.

## Run locally

Open `index.html` in a browser, or serve the directory with any static web server.
